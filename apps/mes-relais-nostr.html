Gestion des relais Nostr

Cette application web Libestria te permet de configurer facilement tes relais Nostr et de mettre à jour tes listes publiques :

  • Relais de lecture (R) et d’écriture (W) — NIP-65 ;
  • Relais de messages privés (DM) — NIP-17 ;
  • Relais de recherche (S) — NIP-51.

Connecte ton compte Nostr

• Nécessite un signer (signataire) de type « extension de navigateur » compatible NIP-07 (Alby Extension, Nostr Map Signer, Nostash…).

• Ta clé privée (NSEC) ne quitte jamais l’extension de ton navigateur.

• Trouve un signer compatible dans Ressources Nostr > Signers (signataires) Nostr de Libestria.

Relais NIP-65 actuellement connectés :

  • 0 relais en lecture (R). Ce sont les relais sur lesquels tu lis les événements Nostr.
  • 0 relais en écriture (W). Ce sont les relais sur lesquels tu publies tes événements Nostr.
