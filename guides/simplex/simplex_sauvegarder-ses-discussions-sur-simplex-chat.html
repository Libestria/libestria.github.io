Sauvegarder ses discussions sur SimpleX Chat

Un guide clair pour exporter, protéger et restaurer tes conversations.

Introduction

SimpleX Chat conserve tes profils et tes discussions dans une base de données locale chiffrée. Exporte-la régulièrement pour pouvoir la récupérer après une panne, une réinstallation ou un changement d’appareil.

1. Préparer la sauvegarde

  1. Ouvre « Paramètres », puis « Phrase secrète et exportation de la base de données ».
  2. Dans « Phrase secrète de la base de données », définis et confirme une phrase secrète longue et difficile à deviner. La phrase aléatoire initiale est conservée sur ton appareil et ne suffit pas pour exporter la base.
  3. Arrête le chat avec « Chat en cours d’exécution » si l’application ne le fait pas pendant la procédure. Authentifie-toi si SimpleX Lock est activé.
Important : conserve la phrase secrète dans un gestionnaire de mots de passe. SimpleX ne peut pas la récupérer si tu la perds.

Les noms des options peuvent varier selon la version. Si tu souhaites seulement transférer tes données, cette sauvegarde contient la base des profils et conversations ; vérifie séparément les fichiers ou médias importants.

2. Exporter et protéger la base

  1. Dans la même rubrique, vérifie que le chat est arrêté et que ta phrase secrète personnelle est définie.
  2. Appuie sur « Exporter la base de données », puis enregistre ou partage l’archive proposée.
  3. Vérifie que le fichier est présent, puis réactive le chat et assure-toi qu’il fonctionne.

Garde au moins une copie hors de l’appareil sauvegardé, par exemple sur un disque externe ou dans un espace cloud sécurisé. Protège l’archive et conserve sa phrase secrète séparément.

La fréquence dépend de ton usage : une fois par mois si tu utilises peu l’application, chaque semaine si tu l’utilises régulièrement, ou après un échange important si tes données changent souvent. Exporte toujours une nouvelle sauvegarde avant une migration.

3. Restaurer la base sur un autre appareil

  1. Transfère la sauvegarde la plus récente — généralement un fichier .zip — sur le nouvel appareil et installe SimpleX Chat.
  2. Crée un profil provisoire, puis ouvre « Paramètres » et « Phrase secrète et exportation de la base de données ».
  3. Arrête le chat, sélectionne « Importer la base de données », puis choisis l’archive et confirme.
  4. Relance le chat et saisis la phrase secrète de la base importée lorsqu’elle est demandée.
Attention : l’importation remplace la base locale, y compris le profil provisoire. Elle ne fusionne pas les données. N’utilise pas une même base sur deux appareils en même temps : cela peut perturber certaines connexions. Vérifie tes profils, contacts et conversations sur le nouvel appareil avant d’effacer l’ancien.

Conclusion

Définis une phrase secrète personnelle, exporte la base chat arrêté, puis protège l’archive et sa phrase secrète. Pour une migration, importe la sauvegarde la plus récente et vérifie les données avant d’effacer l’ancien appareil.
