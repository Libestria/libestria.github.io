Introduction

SimpleX Chat est une messagerie privée qui permet de communiquer sans numéro de téléphone ni identifiant personnel permanent. Les discussions sont conservées principalement dans une base de données locale sur votre appareil, et non dans un historique centralisé accessible à tout moment.

Une sauvegarde régulière permet de limiter le risque de perdre vos conversations en cas de panne, de changement de téléphone ou de réinstallation de l’application.

1. Accéder aux paramètres de sauvegarde

  1. Ouvrez SimpleX Chat.
  2. Accédez aux « Paramètres ».
  3. Recherchez la rubrique « Phrase secrète et exportation de la base de données ».
  4. Ouvrez cette rubrique pour accéder aux options d’exportation et d’importation.

Les intitulés exacts peuvent varier selon la version de l’application.

2. Définir une phrase secrète personnelle

SimpleX chiffre déjà sa base de données avec une phrase secrète aléatoire, conservée de manière sécurisée sur l’appareil. Pour exporter la base, vous devez définir votre propre phrase secrète.

  1. Ouvrez « Phrase secrète et exportation de la base de données ».
  2. Si le chat est actif, désactivez « Chat en cours d’exécution » et confirmez l’arrêt. Selon la version, l’application peut vous demander de l’arrêter au cours de la procédure.
  3. Authentifiez-vous si le verrouillage SimpleX est activé.
  4. Ouvrez « Phrase secrète de la base de données ».
  5. Définissez une phrase secrète robuste, confirmez-la et validez.
Important : conservez cette phrase secrète dans un gestionnaire de mots de passe ou un autre lieu sûr, séparément de l’archive. SimpleX ne peut pas récupérer une phrase secrète perdue.

3. Exporter les discussions

  1. Dans « Phrase secrète et exportation de la base de données », vérifiez que « Chat en cours d’exécution » est désactivé. Arrêtez le chat manuellement si nécessaire.
  2. Vérifiez que votre phrase secrète personnelle a été définie : sans elle, SimpleX ne permet pas l’exportation.
  3. Appuyez sur « Exporter la base de données ».
  4. Enregistrez ou partagez le fichier d’archive proposé par l’application, puis vérifiez qu’il est présent à l’emplacement choisi.
  5. Réactivez systématiquement le chat avec « Chat en cours d’exécution » après l’exportation, puis vérifiez qu’il fonctionne.
À ne pas oublier : le chat doit être arrêté pour l’exportation. Que l’arrêt ait été effectué manuellement ou demandé par l’application, pensez à le réactiver dès la sauvegarde terminée.

La sauvegarde exporte la base de données des profils et conversations. Vérifiez séparément vos fichiers et médias importants : leur inclusion exhaustive dans l’archive n’est pas explicitement garantie par les pages officielles consultées.

4. Conserver la sauvegarde en sécurité

Ne gardez pas votre unique copie sur le téléphone à sauvegarder. Placez-en une autre :

  • sur une clé USB ou un disque dur externe ;
  • sur un ordinateur personnel protégé ;
  • dans un espace cloud sécurisé, avec une protection supplémentaire si nécessaire.

Conservez la phrase secrète dans un gestionnaire de mots de passe. Évitez de partager votre archive avec d’autres personnes : elle contient des informations sensibles.

5. Restaurer les discussions sur un autre appareil

  1. Transférez sur le nouvel appareil la dernière archive de sauvegarde, généralement au format .zip.
  2. Installez SimpleX Chat, ouvrez l’application et créez un profil provisoire avec le nom de votre choix. Ce profil sera remplacé par la base importée.
  3. Ouvrez « Paramètres », puis « Phrase secrète et exportation de la base de données ».
  4. Désactivez « Chat en cours d’exécution » et confirmez l’arrêt.
  5. Choisissez « Importer la base de données », sélectionnez l’archive et confirmez l’importation.
  6. Réactivez le chat ou fermez puis rouvrez l’application. Saisissez la phrase secrète de la base importée lorsqu’elle est demandée.
  7. Vérifiez vos profils, contacts et conversations avant de supprimer les données de l’ancien appareil.
Attention : l’importation remplace la base locale, y compris le profil provisoire. Protégez d’abord toute donnée déjà présente sur l’appareil de destination. N’utilisez pas la même base simultanément sur deux appareils et privilégiez toujours la sauvegarde la plus récente : SimpleX avertit que les bases anciennes ou utilisées en parallèle peuvent perturber les connexions.

6. Précautions essentielles

  • Exportez une sauvegarde avant une réinstallation ou un changement d’appareil.
  • Gardez l’archive la plus récente et sa phrase secrète en lieux sûrs.
  • Ne réutilisez pas simultanément la même base de données sur deux appareils.
  • N’importez pas une ancienne archive si une version plus récente existe : cela risque de perturber les connexions.
  • Après chaque exportation, réactivez le chat et vérifiez son fonctionnement.
  • Avant d’effacer l’ancien appareil, contrôlez les profils, conversations et fichiers essentiels sur le nouveau.

7. À quelle fréquence sauvegarder ?

UtilisationFréquence conseillée
OccasionnelleUne fois par mois
RégulièreUne fois par semaine
Intensive ou professionnelleChaque jour ou après un échange important
Changement de téléphoneJuste avant la migration

Ces fréquences sont des conseils pratiques, pas des exigences de SimpleX.

8. Checklist rapide

Conclusion

Pour préserver vos conversations, définissez une phrase secrète personnelle, arrêtez le chat pour exporter la base, conservez l’archive en sécurité et réactivez le chat après chaque sauvegarde. Pour une migration, utilisez la sauvegarde la plus récente et vérifiez le résultat avant d’effacer l’ancien appareil.
